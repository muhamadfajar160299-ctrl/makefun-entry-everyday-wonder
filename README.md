Entry for the [make.fun](https://make.fun/c/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3)
competition **Everyday Wonder, Two Days to Find the Line**: one sentence, up to
200 characters, on a small moment of wonder in everyday life, judged pairwise
by an AI judge that rewards surprise.

## The entry

> The fridge changed key at 3 a.m., and for a moment the kitchen was humming me to sleep instead of the other way round.

118 characters. The surprise is a small reversal: the appliance that usually
hums in the background is, for one moment, the one doing the soothing.

## How to run

`main.py` (Python 3, standard library only) copies `entry.txt` byte-identical
to `$MAKEFUN_OUTPUT_DIR/entry.txt` with mode `0644`, using no temporary file:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

The output file is then `/tmp/out/entry.txt`.
